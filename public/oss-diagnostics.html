4常见错误诊断

错误码 / 关键字 原因 解决方案
Failed to fetchCORS 跨域拦截OSS 控制台 → Bucket → 数据安全 → 跨域设置（来源: *，Methods: GET/HEAD/PUT/POST）
AccessDeniedRAM 用户无 OSS 权限RAM 控制台 → 用户 → 添加权限 AliyunOSSFullAccess 或自定义 oss:PutObject/GetObject
SignatureDoesNotMatch签名不匹配（时间偏差 / 编码错误）同步系统时间；检查 Object Key 特殊字符
NoSuchBucketBucket 不存在或选错 RegionOSS 控制台 → Bucket 列表确认地域与名称
InvalidAccessKeyIdAccessKey 无效或被禁用检查 RAM 控制台 AccessKey 状态
RequestTimeTooSkewed本地时间偏差 > 15 分钟同步系统时间（控制面板 → 日期和时间）
NetworkingErrorDNS / 代理 / 离线检查网络；endpoint 是否可达

5CORS 规则配置助手

复制以下 JSON 到 OSS 控制台 → Bucket → 数据安全 → 跨域设置 → 创建规则， 或保存为 cors.json 用 ossutil cors --method put 应用。 

[
  {
    "allowedOrigin": "*",
    "allowedMethod": [
      "GET",
      "HEAD",
      "PUT",
      "POST"
    ],
    "allowedHeader": "*",
    "exposeHeader": "*",
    "maxAgeSeconds": "600"
  }
]
