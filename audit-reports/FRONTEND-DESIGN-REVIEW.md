# FocusFlow 界面设计评审（frontend-design 方法论）

> 评审时间：2026-08-29 · 对象：全部 11 个视图 + 全局搜索弹层 + 自习室全屏模式（1440×900，深/浅色双模式截图走查）
> 方法：按 frontend-design 技能的七个评判维度逐项评估——独特性（vs 模板默认）、排版个性、结构即信息、动效克制、文案质量、质量底线、跨视图一致性。
> 结论先行：**这是一套"合格但没有面目"的界面**。工程一致性好、动效克制、深浅色完整；但除了自习室，没有任何一个视图拥有属于自己的视觉记忆点，全部是同一张"标题 + 口号副标题 + 统计卡阵列 + 主卡"的模板脸。

## 一、七维评分

| 维度 | 评分 | 一句话结论 |
|---|---|---|
| 跨视图一致性 | ★★★★☆ | chart 色板/圆角/间距/图标体系统一，深浅色完整——最大优点 |
| 动效克制 | ★★★★ | 无滥用动画（好），但页间切换生硬，缺一处 orchestrated 时刻 |
| 质量底线 | ★★★ | 悬浮计时器遮挡内容、孤立图标、过期日期显示、平板断点缺失 |
| 文案质量 | ★★★ | 空状态是邀请式（好）；口号式副标题与重复按钮文案拉低整体 |
| 结构即信息 | ★★☆ | 多处过滤层冗余、空分组占满屏、同一指标双口径 |
| 排版个性 | ★★ | 全站只有一种标题样式，数字无 tabular，无双层字阶 |
| 独特性 | ★☆ | 10/11 个视图可互换模板脸；唯一例外是自习室——它证明了团队做得出有性格的设计 |

## 二、逐视图发现

### 概览（Dashboard）
- 蓝色渐变问候卡"下午好 17:24"亲切，但副标题"保持节奏，继续前进"是口号 filler。
- 四个快捷入口全部写"点击进入"——同一句话重复四次，按钮本身已说明可点（filler 文案）。
- **数据诚实性**：零数据时"效率评分 15%"照常显示（统计页同指标为 0/100）——同一指标两处口径不同，且无数据却给出确定值，伤害信任。

### 任务
- 标题区"任务与日程 [已收藏 ×] / 正在查看：已收藏"双重表达同一状态。
- 四个优先级分组卡全空时仍占满首屏，"暂无紧急任务"×4——空分组应折叠为一行或收敛。
- 亮点：分组副标题"立即处理/优先安排/正常安排/有空时处理"是好文案（解释了优先级的含义）。

### 专注
- **双重标题**：顶栏"专注"+ 内容区又一个"专注"大标题（日记、时间块同病）。
- 内容区右上角一个孤立的静音图标悬空（与右侧声音控制排重复且无归属）。
- 番茄圆环的紫罗兰渐变是全站少有的"有性格"的时刻，值得保留并发扬。

### 习惯
- 卡片信息密度合适，但每张卡右上角常驻红色垃圾桶——破坏性操作不应与编辑同级常驻。
- 全部为 0 时四张统计卡与卡片网格连续展示 0，缺一个"从哪开始"的引导态。

### 目标
- **结构冗余的典型**：Tab（我的目标/成就墙）+ 四张统计卡 + 类型/分类下拉 + 状态 chips，共四层过滤/汇总叠加在空列表之上。
- 空状态文案是全场最佳："暂无进行中的目标 / 点击上方'新建目标'创建第一个目标"——指明了动作与位置。

### 日历
- 月格干净但过于空旷（每格高而无内容预告），无农历/节假日（V3 已立项）。
- 右侧当日摘要卡（完成/番茄/工时/打卡 + 日程 + 待办）是好的"时间中枢"雏形。

### 时间块
- 副标题宣称"拖拽式时间管理"但页面无任何拖拽（功能债，非纯视觉）。
- 时间线网格干净；右侧"可关联任务"带优先级徽章，信息设计好。

### 纪念日
- **信息自相矛盾**：新年卡显示"2026年1月1日"（已过去的原始日期）但倒计时 125 天（正确指向 2027）——应显示下一次实际纪念日。
- 编辑/删除图标常驻每卡（同习惯页问题）。

### 日记
- 同一动作三个名字：顶栏"+ 写日记"、空状态按钮"开始写日记"、副标题提示"点击'写日记'开始记录"。
- 空状态居中但四周大量死空间，是全站最"空"的一屏。

### 统计
- 五张着色统计卡排列舒适；"应用时间线"卡的桌面端限制说明诚实清楚（好文案）。
- 与概览的评分口径不一致（见上）。

### 自习室（本次新设计）
- 全站唯一有 signature element 的视图：黑板+粉笔+桌牌的教室隐喻贯穿到底，全屏模式"整屏即黑板"。应作为其他视图改造的标杆。

### 全局件
- **悬浮计时器**（右下角 25:00）在每个视图都遮住右下角内容，无避让机制。
- 搜索弹层：打开时只有孤零零一个输入框，无最近搜索/快捷结果，首帧价值为零。
- 侧边栏折叠/展开状态在视图间偶发不一致（截图中出现过一次丢标签）。

## 三、对照"模板默认"的校准

frontend-design 技能点名三种 AI 模板脸（奶油底+衬线+赤陶 / 近黑底+荧光绿 / 报纸风）。本应用不属于这三者，但落在第四种更隐蔽的默认里：**shadcn 白卡仪表盘**——每个视图都是"页标题 + 灰色副标题 + 3~5 张统计卡 + 一张主卡"。模板本身不是罪（一致性正是优点），罪在 11 个视图共用一张脸而没有任何一个视图长出自己的脸。

## 四、建议（按投入产出排序）

### P1 · 建立每视图的签名元素（把自习室的方法推广）
不必每页都做黑板，但每页应有一个"只属于它"的视觉锚点：
- **概览**：问候卡改成"今日黑板报"——用自习室的黑板材质画今日三行板书（专注/任务/习惯各一行粉笔小结），全站语言立刻串起来。
- **任务**：清单用纸面质感（细横线底纹），完成项划线用"手写笔触"而非纯 CSS line-through。
- **统计**：图表统一"墨水风"——同一笔触/同一色系渐变，去掉五张卡的彩色底，让数据本身当颜色。
- **专注**：保留紫罗兰圆环，删掉双重标题与孤立图标。

### P2 · 文案与数据诚实
- 删除全部口号副标题（"保持节奏，继续前进"式），副标题改为说明这一页能做什么。
- 四个"点击进入"删除；"写日记/开始写日记"统一为一个动词。
- 空数据显示"——"而非编造值；效率评分全站统一口径。
- 破坏性操作（垃圾桶）收进"…"菜单。

### P3 · 结构减负
- 目标页：统计卡与状态 chips 合并为一行，下拉过滤收进"筛选"按钮。
- 任务页：空分组折叠为单行计数条，主屏让给"今日/最近"内容。
- 搜索弹层首帧显示最近任务/常用视图。

### P4 · 细节修缮
- 双重标题（顶栏 vs 内容区）二选一。
- 悬浮计时器增加主体内容右下避让（padding）。
- 纪念日显示"下一次实际日期"；孤立静音图标归位。
- 平板断点（V2 已知）与列表虚拟化列入工程排期。

## 五、结论

FocusFlow 的界面工程底子（一致性、克制、深浅色、空状态文案）在同规模项目里属于中上，但它现在是一间"每间房都长一样的酒店"——而自习室证明了这栋楼可以做得出有性格的房间。下一步不需要推翻重来，只需要把自习室的设计方法（主题锚定 → 材质库 → 一个签名元素 → 其余保持安静）应用到其余十个视图，并完成文案与数据诚实性的清债。
